# 🎨 Modular CSS Box-Shadow Generator

Aplikasi web interaktif ringan untuk merancang efek bayangan kotak (*box-shadow*) secara *real-time* sekaligus menyalin kodenya dalam satu klik. Proyek ini dibangun murni menggunakan **Vanilla JavaScript (ES Modules)** dengan menerapkan prinsip pemisahan kode yang bersih (*Separation of Concerns*).

## ✨ Fitur Utama
- **Kontrol Real-Time:** Sesuaikan *Horizontal Offset*, *Vertical Offset*, *Blur Radius*, *Spread Radius*, *Opacity*, dan warna bayangan menggunakan *slider*.
- **Mode Inset:** Opsi untuk beralih antara bayangan luar (normal) dan bayangan dalam (*inset*).
- **Salin Otomatis:** Tombol penyalin kode CSS instan ke *clipboard* dengan umpan balik visual (*feedback* teks "Tersalin!").
- **Arsitektur Modular:** Kode JavaScript dipecah ke dalam modul-modul terpisah (`utils.js`, `ui.js`, `main.js`) untuk menjaga kerapian dan kemudahan pemeliharaan.
